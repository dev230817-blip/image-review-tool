# 验证记录

## 2026-11-25：框选合并检查

在现有 v3 上移植框选功能，保留双人比对和分次导入流程。合并版使用 Windows、Microsoft Edge、Python 3.13 和 Node.js 24 验证，通过 26 项新增浏览器检查及 11 项原功能回归检查。

新增检查使用 2005 张虚构图片，预置 1700 条个人标注及淘汰原因，覆盖：

- 鼠标拖动框选、紫色提示、上下和左右边缘自动滚动、页底停止。
- 键盘与底部按钮批量 Yes／No、批量清除、整批撤销；逐条比对其余 1692 条旧记录未被改动。
- 未筛选视图下批量、每页 1000 张的边界、跨页自动下一张、切换模式或查看条件取消选择。
- Esc 中止拖动、窗口失焦、单击、双击预览、书签及窄窗口布局。
- 双人批量复核跳过待补筛图片，只修改最终结果，保留两人的原始判断。
- 恢复双方一致结论，撤销时恢复原有复核时间和“需重新核对”标记。
- 刷新后恢复、汇总导出和直接打开 HTML 的框选操作；运行中无未捕获脚本错误。

11 项原功能回归重新检查了逐份暂存 CSV、刷新后补第二份、身份和内容校验、分类计数、单独替换一人、同人结果拦截、第三人复核、直接打开 HTML 等流程，全部通过。

Python 服务端逐字节保持原版本，浏览器存储键及 CSV 内部格式版本保持 v3。新增测试见 [tests/README.md](../tests/README.md)，截图中的图片与筛选身份均为虚构测试内容。

## 2026-11-25：当前工具功能检查

合并前的发布包与当时桌面可用版本逐字节一致。该版本使用 1005 张虚构图片通过 11 项检查：

1. 个人模式保留下拉框，双人模式使用五个横向分类按钮。
2. 单份 CSV 可先暂存，关闭弹窗、刷新后能补第二份。
3. 分次导入后仍核对身份、批次和内容，再开始比对。
4. 五类计数与实际显示的图片数量一致。
5. 数字键复核、自动下一张、撤销正常；裁决不改写原始分歧数量。
6. 单独替换甲的 CSV 后，乙的结果保留，原裁决按需提示复核。
7. 重复或同人 CSV 会被拦截，失败不覆盖已有比对。
8. 仍可一次选两份，也可在校验窗口只换一份。
9. 宽屏横排、窄窗口换行，图片维持四列。
10. 直接打开 HTML 时，逐份拖入和选择 CSV 均可使用。
11. 浏览器无未捕获脚本错误。
